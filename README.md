# 모집공고2

배틀그라운드 팀원을 모집하는 Discord 봇입니다. 슬래시 명령어로 모집 공고를 만들고 참여 버튼으로 인원을 관리할 수 있습니다.

## 주요 기능

- 시간, 게임 종류, 인원, 음성 채널을 지정해 구인 공고 생성
- `/빠른양식`으로 버튼 설정 없이 즉시 공고 생성
- 참여·참여취소 버튼과 작성자 자동 참여
- 작성자 또는 서버 관리자·서버 주인의 공고 수정 및 삭제
- 서버별 음성 채널 화이트리스트와 구인 기록 저장
- 관리자에 의한 타인의 공고 삭제 시 작성자에게 DM 알림

## 설치 및 실행

### 1. 준비

- Python 3.11 권장 (`requirements.txt`는 Python 3.11 기준으로 생성)
- Discord 봇 애플리케이션과 봇 토큰
- Discord 개발자 포털의 Bot 설정에서 **Server Members Intent**와 **Message Content Intent** 활성화
- 봇을 서버에 초대할 때 `bot`과 `applications.commands` 범위 지정

구인 채널에서 봇이 채널 보기, 메시지 보내기, 링크 임베드, 메시지 기록 보기, 모두 멘션하기 권한을 갖도록 설정하세요.

### 2. 설치

```bash
git clone https://github.com/pafq202/-OOP.git
cd -OOP
python -m venv .venv
```

현재 `.gitignore`는 `.venv/`를 제외하지 않으므로 가상 환경 파일을 커밋하지 않도록 주의하세요.

가상 환경을 활성화합니다.

```bash
# Linux/macOS
source .venv/bin/activate

# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
pip install -r requirements.txt
```

### 3. 토큰 설정

프로젝트 루트의 `.env`에서 `YOUR_BOT_TOKEN_HERE`를 실제 봇 토큰으로 바꾸세요.

```dotenv
DISCORD_TOKEN=YOUR_BOT_TOKEN_HERE
```

또는 실행 환경에 `DISCORD_TOKEN` 환경 변수를 설정할 수 있습니다. 이미 설정된 환경 변수는 `.env` 값보다 우선합니다.

**주의:** 저장소의 `.env`는 Git에서 이미 추적 중입니다. `.gitignore`에 포함되어 있어도 실제 토큰을 넣은 변경 사항을 커밋하거나 공개하지 마세요. 토큰이 노출되었다면 Discord 개발자 포털에서 재발급하세요.

### 4. 실행

```bash
python main.py
```

시작 시 `cogs/`의 확장 기능을 불러오고 슬래시 명령어를 동기화합니다.

## 사용 방법

### 음성 채널 설정

서버 관리자 또는 서버 주인이 `/설정`을 실행하고 구인에 사용할 음성 채널을 선택합니다. 선택한 화이트리스트에 등록된 채널만 `/양식`, `/빠른양식`, `/수정`에서 사용할 수 있습니다. 전체 해제하면 표시되는 채널이 없어집니다.

설정 화면은 음성 채널을 이름순으로 정렬해 처음 25개까지 표시합니다. 구인 채널 선택과 자동완성도 최대 25개를 표시합니다.

### 구인 생성과 참여

1. `/양식`을 입력하고 시간, 종류, 인원, 음성 채널을 설정합니다. 인원은 2~4명입니다.
2. 네 항목을 모두 입력하면 해당 텍스트 채널에 `@here`와 함께 공고가 게시되고 작성자가 첫 번째 슬롯에 등록됩니다.
3. 다른 사용자는 공고의 **참여** 또는 **참여취소** 버튼을 사용합니다. 중복 참여와 정원 초과는 허용되지 않습니다.

버튼 대신 `/빠른양식`에서 `시간`, `종류`, `인원`, `채널`을 지정해 바로 게시할 수도 있습니다. 채널은 화이트리스트에 등록된 이름을 자동완성 목록에서 선택하세요. 여러 사용자가 각각 `/양식`을 설정할 수 있습니다.

### 구인 수정과 삭제

- `/수정`: 파라미터로 공고(자동완성)와 변경할 항목(시간, 종류, 인원, 채널)을 입력합니다. 입력한 항목만 변경되고 나머지는 기존 값이 유지됩니다. 인원을 줄이면 초과 슬롯의 참여자가 제외됩니다.
- `/삭제`: 목록에서 공고를 선택해 삭제합니다. 관리자가 다른 사람의 공고를 삭제하면 작성자에게 DM을 시도합니다.

두 명령어는 공고가 게시된 **텍스트 채널에서** 실행하세요. 본인의 공고를 관리할 수 있으며, 관리자와 서버 주인은 같은 서버의 다른 사용자 공고도 관리할 수 있습니다.

## 명령어

| 명령어 | 기능 | 사용 권한 |
| --- | --- | --- |
| `/양식` | 버튼으로 공고 설정 | 서버 사용자 |
| `/빠른양식` | 항목을 직접 입력해 공고 생성 | 서버 사용자 |
| `/수정` | 기존 공고 설정 변경 | 작성자, 관리자 또는 서버 주인 |
| `/삭제` | 기존 공고 삭제 | 작성자, 관리자 또는 서버 주인 |
| `/설정` | 구인에 표시할 음성 채널 선택·초기화 | 관리자 또는 서버 주인 |
| `/초대링크` | 코드에 설정된 봇 초대 링크 표시 | 관리자 또는 서버 주인 |

`/초대링크`는 이 프로젝트에 고정된 봇의 링크를 표시합니다. 별도의 봇을 직접 운영한다면 Discord 개발자 포털에서 해당 봇의 초대 링크를 만들어 사용하세요.

## 데이터와 설정

실행 중 `data/` 디렉터리가 생성되며 Git에는 포함되지 않습니다.

| 파일 | 내용 |
| --- | --- |
| `data/pending_recruitment.json` | 진행 중인 공고, 작성자와 참여자 정보 |
| `data/recruitment_history.json` | 공고 생성·수정 정보, 참여 기록, 삭제자 및 삭제 시각 |
| `data/voice_whitelist.json` | 서버별 구인용 음성 채널 목록 |
| `data/server_info.txt` | 봇이 연결된 서버 정보 |
| `data/server_log.txt` | 봇의 서버 추가·제거 기록 |

구인 기록에는 서버 이름과 사용자 닉네임 등이 포함될 수 있습니다. 공고를 `/삭제`해도 `recruitment_history.json`의 기록은 남으므로 파일 접근과 보관에 유의하세요.

공고 정보는 파일에 저장되지만, `main.py`는 재시작 시 기존 공고의 버튼 뷰를 자동 등록하지 않습니다. 재시작 후 기존 공고의 버튼이 작동하지 않으면 공고가 게시된 채널에서 `/수정`으로 항목을 하나 이상 변경하여 공고를 갱신하세요.

`config/config.ini`와 `config/comment.ini`는 시작 시 읽지만, 현재 구인 기능은 해당 설정값을 사용하지 않습니다. 봇 토큰은 `config.ini`의 `token` 항목이 아닌 `.env` 또는 환경 변수의 `DISCORD_TOKEN`에서 읽습니다.

│   └── recruitment.py    # 구인 명령어와 버튼
├── config/

├── utils/

## 문제 해결

- **봇이 시작되지 않음:** `.env`의 토큰과 필요한 Discord Gateway Intent 설정을 확인하세요.
- **슬래시 명령어가 보이지 않음:** 봇이 `applications.commands` 범위로 초대되었는지와 실행 로그의 동기화 오류를 확인하세요.
- **음성 채널이 보이지 않음:** 관리자가 `/설정`에 해당 채널을 등록했는지 확인하세요. 설정 화면에는 처음 25개 채널만 표시됩니다.
- **공고 수정이나 삭제가 실패함:** 공고가 게시된 텍스트 채널에서 실행하고 작성자 또는 관리자 권한이 있는지 확인하세요.

문제가 계속되면 [Issues](https://github.com/pafq202/-OOP/issues)에 알려주세요.
